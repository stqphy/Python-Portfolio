# Semester1-Portfolio
This is where I store my Python projects for Semester 1.

### MadLibs:
This program allows users to input words for a given prompt: noun, verb, adjective, etc. After the user inputs word(s) for the given prompts, a story will be generated using those words.

### Multiplication Quiz:
This program allows users to quizzes the user on multiplication problems and displays their score after each round. Each round consists of 5 questions and your score, how many questions you got correct and how many questions you get wrong, are displayed. 

 ### Name Generator:
This program allows users to find out which Crumbl Cookie they are by going through nested questions. There are 3 questions that you have to answer to find out the end result. 

### Pokemon App:
This program allows users to train their Pokémon, battle in gyms, and watch it evolve as its level increases. You get to input which action you would like to do with your Pokemon. You can also display the current name of pokemon, it's current level, and an image of the current pokemon. User can choose to quit whenever they would like. 

### Rock Paper Scissors:
This program allows users to play "Rock-Paper-Scissors" against the computer. You have to type your move, either rock, paper, or scissors, while the computet randomly generates a move. After each round, the number of wins for the player and computer, along with the ties, are displayed.
